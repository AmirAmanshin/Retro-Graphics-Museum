# Retro Graphics Museum
Этап 1: Базовая архитектура и генерация геометрии

    Инициализация контекста: Настройка GLFW-окна, подключение загрузчика профиля OpenGL (GLAD/GLEW) и интеграция математической библиотеки GLM.

    Логика лабиринта: Реализация алгоритма Recursive Backtracker, который на выходе отдает структуру данных (например, двумерный массив), где обозначены пустые клетки и стены.

    Построение мешей: Написание генератора геометрии, который проходит по массиву лабиринта и формирует буферы вершин (VAO/VBO/EBO) для стен, пола и потолка.

Этап 2: Камера, управление и коллизии

    Математика камеры: Создание универсального класса камеры (вычисление матриц View и Projection, расчет векторов Front/Right/Up на основе углов Pitch и Yaw). Сначала лучше сделать полнофункциональную свободную камеру, чтобы позже ограничивать её логикой состояний.

    AABB-коллизии: Написание системы проверки пересечений позиций игрока с координатами заполненных ячеек сетки. Важно реализовать векторное скольжение вдоль стен для комфортного перемещения.

    State Machine: Разработка контроллера, который управляет текущей "Эрой", диктуя ограничения камере (свободная, только по оси Y, дискретная) и указывая рендеру, какие шейдеры использовать.

Этап 3: Эра 1 (Векторная графика) и система прогрессии

    Базовый рендеринг: Написание простейшей пары шейдеров (умножение на MVP матрицу + константный зеленый цвет). Включение режима glPolygonMode(GL_FRONT_AND_BACK, GL_LINE).

    Дискретная механика: Привязка ввода к логике перемещения строго по центрам клеток (с использованием интерполяции для плавности) и жестким поворотам на 90 градусов. Реализация механики "вытягивания шеи" (увеличение Position.y камеры).

    Триггеры уровней: Добавление зоны выхода в лабиринте, при достижении которой контроллер меняет стейт игры на Эру 2 и пересобирает геометрию.

Этап 4: Интеграция текстур и освещения (Эры 2 и 3)

    Эра 2 (Псевдо-3D): Подключение библиотеки вроде stb_image для загрузки пиксель-арта. Добавление UV-координат в вершинные буферы. Активация GL_FILL и текстурной фильтрации GL_NEAREST. Блокировка обзора по вертикали в классе камеры.

    Эра 3 (Аппаратное 3D): Добавление расчета нормалей при генерации мешей стен. Написание комплексного фрагментного шейдера (модель освещения Фонга с динамическим Point Light в координатах игрока). Перевод фильтрации в GL_LINEAR и разблокировка полного mouselook.
